# 03 — Katas Python

Colección de **40 katas de programación** resueltas en **Python** mediante Jupyter Notebooks. Cada kata incluye el enunciado del problema, una o varias soluciones y ejemplos de ejecución con sus resultados.

---

## Descripción

Las katas son ejercicios breves pensados para practicar la lógica de programación y las estructuras de datos del lenguaje. En este cuaderno de trabajo se abordan, entre otros:

- Manipulación de **cadenas de texto** (frecuencias, conteos, transformaciones).
- **Estructuras de datos**: listas, diccionarios, conjuntos y tuplas.
- **Funciones** y documentación mediante *docstrings*.
- Control de flujo, bucles y condicionales.
- Algoritmos básicos de ordenación y búsqueda.

---

## Contenido

Cada ejercicio está en su propio notebook, numerado del 1 al 40:

```
Ejercicio1.ipynb
Ejercicio2.ipynb
...
Ejercicio40.ipynb
```

Cada notebook sigue la misma estructura:

1. **Enunciado** de la kata.
2. **Ejemplo(s)** de uso y resultado esperado.
3. **Solución** implementada y comentada.

---

## Tecnologías

- **Python 3**
- **Jupyter Notebook**

---

## Cómo ejecutar

1. Instala Jupyter si no lo tienes:

   ```bash
   pip install notebook
   ```

2. Inicia el servidor de Jupyter desde esta carpeta:

   ```bash
   jupyter notebook
   ```

3. Abre cualquiera de los archivos `Ejercicio*.ipynb` y ejecuta las celdas con `Shift + Enter`.

> También puedes abrir los notebooks en **Visual Studio Code** instalando la extensión de Jupyter.
