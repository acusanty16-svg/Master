# Primer Trabajo — Portafolio Web

Página web de **portafolio personal** desarrollada con **HTML5** y **CSS3**. Es el primer trabajo de maquetación del máster y recoge gustos, aficiones e inspiraciones del autor en un diseño de una sola página.

---

## Descripción

El sitio presenta la información en varias secciones navegables mediante anclas internas, con un estilo propio basado en tipografías de Google Fonts (*Bebas Neue* y *Roboto*) y una paleta de colores definida con variables CSS.

---

## Secciones

- **Introducción** — nombre y presentación.
- **Mis hobbies** — música (bandas) con vídeos incrustados.
- **Religión** — contenido audiovisual relacionado.
- **Lecturas** — libros recomendados.
- **Mis inspiraciones** — personas y referentes.
- **Contacto** — correo y dirección.

---

## Estructura

```
Primer-Trabajo-Master/

├── style.css       # Estilos: variables, tipografías y layout
├── assets/

```

---

## Tecnologías

- **HTML5** (estructura semántica, `iframe` de YouTube)
- **CSS3** (variables, `@import` de fuentes, `box-shadow`, `border-radius`)
- **Google Fonts**

---

## Cómo visualizar

Abre el archivo `index.html` directamente en el navegador, o sírvelo con una extensión como *Live Server* de Visual Studio Code.
