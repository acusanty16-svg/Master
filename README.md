# Master — Desarrollo de Software

Repositorio principal del **Máster en Desarrollo de Software**. Recopila apuntes, prácticas y proyectos organizados por año y por área de conocimiento.

---

## Descripción

El repositorio está estructurado en dos años académicos. El **primer año** agrupa las áreas de *Frontend*, *Backend* y los *proyectos prácticos*; el **segundo año** recoge el trabajo del curso en curso.

## 1er Año

### 01 — Frontend

Desarrollo de interfaces web con **HTML5**, **CSS3** y **JavaScript (ES6+)**: estructura semántica, estilos, manipulación del DOM y proyectos con **Vite**.

### 02 — Backend

- **NoSQL** — Desarrollo de APIs REST con **Node.js**, **Express** y **MongoDB**: rutas, controladores, modelos y conexión a base de datos.
- **Python** — Fundamentos del lenguaje: variables, funciones, estructuras de datos y control de flujo.
