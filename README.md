# Master — Desarrollo de Software

---

## Descripción

Repositorio con el contenido del **Máster en Desarrollo de Software**, organizado por áreas: Frontend, Backend y Proyectos prácticos.

---

## Estructura

```
Master/
└── 1er-Año/
    ├── 01-Frontend/               # Desarrollo de interfaces web
```

---

## Contenido

### 01 — Frontend
Desarrollo de interfaces de usuario modernas con tecnologías web. HTML5, CSS3, JavaScript ES6+, DOM manipulation y frameworks front-end.

### 02 — Backend

#### NoSQL
Desarrollo de APIs REST con **Node.js**, **Express** y **MongoDB**. Rutas, middlewares, controladores, modelos y conexión a bases de datos NoSQL.

#### Python
Fundamentos de programación en **Python**: variables, funciones, estructuras de datos, control de flujo, manejo de excepciones y librerías.

### 03 — Proyectos

#### Primer Trabajo — Interface Web
Proyecto de desarrollo de una interfaz web completa con HTML, CSS y JavaScript. Diseño responsive, navigación y componentes visuales.

#### Segundo Trabajo — Ejercicios JavaScript
Colección de ejercicios practicos:
- **Ejercicios DOM** — Manipulación del DOM y eventos
- **Ejercicios ES6+ y asincrónica** — Promesas, async/await, fetch API
- **Ejercicios básicos y avanzados** — Lógica de programación en JavaScript

---

## Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript ES6+, Vite
- **Backend:** Node.js, Express, Python
- **Bases de datos:** MongoDB
- **Herramientas:** Git, GitHub, VS Code
